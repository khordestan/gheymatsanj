# قیمت‌سنج

ابزار فارسی بررسی قیمت دیجی‌کالا و مقایسه با نتایج هم‌نام در ترب. لینک مستقیم محصول دیجی‌کالا را وارد کنید تا قیمت تنوع پیش‌فرض به تومان نمایش داده شود.

سابقهٔ قیمت از اولین بررسی در همان مرورگر ثبت می‌شود. قیمت فعلی با کمترین قیمت ثبت‌شده در روزهای قبل، در بازهٔ ۳۰ روزه و برای همان تنوع، مقایسه می‌شود. قیمت اعلام‌شدهٔ ترب ممکن است برای رنگ یا گارانتی متفاوت باشد. موجودی، قیمت نهایی و هزینهٔ ارسال را در صفحهٔ فروشنده بررسی کنید.

## ساخت و اجرای محلی

به Node.js نسخهٔ ۲۲ یا جدیدتر و برای اجرای محلی به Wrangler نیاز دارید.

```sh
node build.mjs
npx wrangler dev dist/server/index.js --compatibility-date 2026-01-01
```

نشانی محلی چاپ‌شده در ترمینال را باز کنید. اجرای بررسی قیمت به دسترسی شبکه به دیجی‌کالا و ترب و در دسترس بودن پاسخ‌های آن‌ها وابسته است. خروجی ساخت یک ماژول Cloudflare Worker در `dist/server/index.js` است.
